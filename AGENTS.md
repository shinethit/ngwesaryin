# Project Instructions & User Communication Guidelines

## Error Reporting & Resolution Workflow
Whenever the user reports an error or unexpected behavior, the assistant MUST provide a clear, structured explanation with the following:
1. **Root Cause (ဘာကြောင့် ဖြစ်ရတာလဲ)**: Clearly investigate and explain the exact technical or logical cause in easy-to-understand Myanmar language.
2. **How It Was Fixed (ဘယ်လို ပြင်ဆင်ထားပေးခဲ့လဲ)**: Explain step-by-step how the issue was fixed and what logic was modified.
3. **Verification (စမ်းသပ်စစ်ဆေးမှု ရလဒ်)**: Mention how it was verified to ensure the problem will not reoccur.
